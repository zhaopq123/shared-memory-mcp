**结论（PASS）**：两段式 / 全文直进 = **41.0%**（阈值 50%）。

- 语料：`demo-vault` 全量 + 1 条合成长文档（详见脚本 docstring）
- 工作负载：搜索命中 **6** 条，agent 回读 **2** 条正文

标题/类型/时间/相关度；判断完只回读真要看的那几条。列表 200 条时
全文直进会把返回体撑爆，也会浪费 agent 的上下文预算。
